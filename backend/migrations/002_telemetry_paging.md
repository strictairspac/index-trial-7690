# Schema v2
telemetry_versions(record_id, version, recorded_at, sensor_id, device_type, value) is an append-only version store with primary key (record_id, version) and index (recorded_at, record_id). Backfills and corrections append a new version of the record; rows are never updated in place, so in-progress paging is never reshuffled. page_pins(snapshot, expires_at) pins the snapshot version of every live page cursor (10-minute TTL, PAGE_CURSOR_TTL). meta_kv holds telemetry_seq (global version counter, also the mutex row serializing begin/next/gc critical sections) and page_cursor_secret (HMAC key for signed cursors); both persist, so cursors stay valid across restarts. POST /telemetry/pages/gc deletes only versions invisible to every unexpired pin and to the current version; versions pinned by a live cursor remain pageable.
